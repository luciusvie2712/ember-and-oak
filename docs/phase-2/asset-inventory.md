# 10. Technical image requirements

Every production image should have:

- Original/master retained.
- Known width/height.
- Responsive variants generated by delivery pipeline.
- AVIF/WebP where supported.
- Correct compression.
- No unnecessary metadata payload.
- Focal point for asymmetric crop where needed.
- Alt text strategy.
- Lazy-load eligibility defined.
- Critical/preload flag only for actual above-fold media.

---

# 11. Video requirements

If used:

- Short duration.
- Optimized bitrate/resolution.
- Poster image.
- No heavy autoplay on mobile.
- Muted autoplay only if UX later approves.
- Reduced-motion fallback.
- Captions if spoken/audio content is meaningful.

---

# 12. Rights and privacy

For guest photography:

- Confirm permission/model release if required.
- Avoid publishing identifiable guests without appropriate rights.

For supplier/farmer photography:

- Confirm source/usage rights.

Do not use unverified "Michelin/award" visual claims.
