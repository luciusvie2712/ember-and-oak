# EMBER & OAK — VISUAL DESIGN DIRECTION

Status: **APPROVED DESIGN BASELINE**

## 1. Brand expression

The UI should feel:

- Warm.
- Dark.
- Mature.
- Quietly luxurious.
- Culinary.
- Editorial.
- Contemporary.

It should not feel:

- Corporate.
- SaaS.
- Ecommerce-first.
- Fast-food.
- Flashy luxury.
- Over-decorated.

## 3. Core composition rules

### Large type before small decoration

A page section should generally communicate through:

1. Strong heading.
2. Image.
3. Supporting copy.
4. Small label/divider.

Do not fill empty space with unnecessary icons or decorative cards.

### Asymmetry

Prefer compositions such as:

```text
5 columns text / 7 columns image
4 columns image / 6 columns text with offset
8 columns full image / 4 columns quote
```

instead of repeated 6/6 split everywhere.

### Negative space

Whitespace is intentional.

Large vertical spacing should separate narrative chapters rather than putting every section inside a container box.

### Image overlap

Allowed selectively:
- Hero secondary media.
- Chef signature.
- Small editorial detail image.

Avoid:
- overlapping form controls,
- overlapping operational information,
- decorative overlap that harms mobile readability.

## 4. Surface strategy

Public website:

```text
dark dominant
cream editorial interludes
full-bleed media
minimal borders
```

Reservation:

```text
dark premium shell
high clarity form surface
less visual ambiguity
```

Admin:

```text
functional neutral application UI
brand-aware but not editorial-heavy
```

Admin must prioritize density and operational clarity over immersive storytelling.

## 5. Accent philosophy

Burnt Orange is a signal, not a theme fill.

Use for:
- primary CTA.
- active navigation.
- menu index hover.
- small labels.
- focused selected time slot.
- divider/accent line.
- small status emphasis where semantic use is appropriate.

Avoid:
- entire large background sections.
- long body text.
- large decorative gradients.
- every icon.

## 6. Border philosophy

Borders should be subtle:

```text
dark surface border: rgba(246, 241, 232, 0.14)
cream surface border: rgba(23, 21, 18, 0.16)
```

Use 1px separators instead of cards/shadows where possible.

## 7. Radius philosophy

Editorial public UI should be mostly square or nearly square.

Recommended:
- `0px` primary editorial containers.
- `2px` fields/buttons only if rendering benefits.
- pill radius only for compact selectable chips/time slots if visual design requires it.

Avoid generic `12px/16px` SaaS card rounding across the public site.

## 8. Shadow philosophy

Public UI:
- almost no box shadows.
- use contrast, overlay, border and depth through photography.

Admin:
- subtle elevation allowed for popovers/dialogs.

## 9. Iconography

Use icons only when they improve comprehension:
- menu trigger.
- arrow.
- calendar.
- chevron.
- close.
- external directions.
- status/system controls.

Style:
- simple line icons.
- consistent optical weight.
- no decorative icon set in editorial sections.

## 10. Visual differentiation

The site should be recognizable through:

- oversized serif title.
- controlled dark palette.
- asymmetric image rhythm.
- interactive editorial menu.
- full-bleed atmosphere section.
- strong quotation typography.
- restrained orange accents.

Not through:
- gradients,
- neon glow,
- glassmorphism,
- excessive animation.
